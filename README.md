# Conversor de Temperatura

Programa interactivo en JavaScript para convertir grados Celsius a Fahrenheit y Kelvin.

---

## Características

- **Conversión Instantánea**: Calcula Fahrenheit y Kelvin a partir de un valor en Celsius.
- **Validación de Entradas**: Detecta y alerta si la entrada no es un número válido.

---

## Uso

1. Ingresa un valor numérico en el campo de texto (ej. `25` o `45`)
2. Presiona **Enter** o haz clic en **Ejecutar**.
